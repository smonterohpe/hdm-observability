Hospital Discharge Manager

Simulador de gestión de altas médicas hospitalarias para demos de continuidad de negocio con Zerto. El RBG genera altas ficticias continuamente para demostrar el impacto de un incidente y la recuperación con RPO de segundos.

Todos los datos de pacientes, diagnósticos y médicos son completamente ficticios.
