Demo Engine — escenarios de continuidad de negocio

🔄 Failover Test

Inicia un Failover Test no disruptivo. El VPG pasa a modo test y el tráfico se redirige a la réplica. Las altas siguen procesándose en el site DR.

⚠️ Error Humano

Simula el borrado accidental de la tabla de altas por un operador. Los KPIs caen a cero. Usa el Journal de Zerto para hacer el recovery.

💀 Ransomware (Wario)

Wario cifra la base de datos. Los datos de pacientes quedan inaccesibles. Demostración de recovery con RPO de segundos desde el Zerto Journal.

✅ Recovery (Zerto Journal)

Ejecuta el recovery desde el Journal de Zerto. El sistema vuelve al punto anterior al incidente. El RBG se reanuda automáticamente.

Hospital Discharge Manager

Simulador de gestión de altas médicas hospitalarias diseñado para demostrar las capacidades de continuidad de negocio de Zerto. El sistema genera altas médicas ficticias de forma continua mediante el RBG (Random Booking Generator), permitiendo demostrar en tiempo real el impacto de un incidente y la recuperación con RPO de segundos.

Todos los datos de pacientes, diagnósticos y médicos son completamente ficticios y generados aleatoriamente. No se usa ni almacena ningún dato real de pacientes.
